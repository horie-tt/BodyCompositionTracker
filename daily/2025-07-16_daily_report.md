## 苦労した点

- **ESMモジュール問題の根深さ**: `src/__tests__/api.test.ts`で`isows`パッケージのESM importエラーが発生。Supabaseの依存関係チェーンが複雑で、モック化とenvironment変数の両方で対応が必要だった

- **テストの警告ノイズ**: `Invalid/Timezone`を使ったエラーハンドリングのテストで大量の`console.warn`が出力され、テスト結果が見づらくなった。`console.warn`をモック化する適切な方法を検討するのに時間がかかった

- **CI環境とローカルの違い**: GitHub Actions（ubuntu-latest）では`Intl API`が`"UTC"`を返すのに対し、ローカルでは`"Asia/Tokyo"`を返す。この環境差によるテスト失敗の原因特定に苦労した

- **getCurrentDateInTimezone関数の実装**: 既存の`toLocaleString`→`new Date()`の変換が不正確で、ユーザーの要求である「本日の日付設定」が正しく動作していなかった。`Intl.DateTimeFormat`の正しい使い方を理解するのに時間がかかった
